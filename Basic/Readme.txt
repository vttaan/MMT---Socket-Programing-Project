Đây là phần basic của đồ án, những điểm chính là:

-Xác thực thông qua log in (user và password)

-Gửi file (server)

-Tải file(clients)

Những cú pháp có thể thắc mắc:
"\r\n" ý nghĩa là giống phím "Enter" trong máy tính, báo hiệu là kết thúc câu, nếu không có thfi server bị đứng

Ưu điểm khi làm UDP vứoi TCP:
-Khi gửi file có dung lượng thấp thfi nhanh hơn so với TCP và sẽ có mất mát ít hơn
